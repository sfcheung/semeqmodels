# Changelog

## semeqmodels 0.1.0.5

### New Features

- Added the argument `passes` to
  [`eq_models()`](https://sfcheung.github.io/semeqmodels/reference/eq_models.md)
  for checking empirical equivalences in two or more datasets. The
  additional dataset are resample-with-replacement versions of the
  original dataset. (0.1.0.2)

- Added
  [`est_summary()`](https://sfcheung.github.io/semeqmodels/reference/est_summary.md)
  to summarize parameter estimates across models generated by
  [`eq_models()`](https://sfcheung.github.io/semeqmodels/reference/eq_models.md).
  The output has a `print` method
  ([`print.est_summary()`](https://sfcheung.github.io/semeqmodels/reference/est_summary.md)).
  (0.1.0.3, 0.1.0.4)

- Added the option to define empirical equivalence using the implied
  covariance matrix (and mean vector, if available). Whether fit
  measures or implied matrices and vectors are used is determined by the
  argument `eq_mode`. (0.1.0.5)

### Miscellaneous

- Updated only the GitHub `README.md`. No change to the codebase.
  Identical to 0.1.0 otherwise. (0.1.0.1)

## semeqmodels 0.0.1

- First public release for testing. (0.0.1)

- Added tests using `dagitty`. (0.0.1.1)

- Updated `eq_models_internal()` to automatically mark the original
  models, and updated
  [`partables_plots()`](https://sfcheung.github.io/semeqmodels/reference/plot_partables.md)
  to retrieve the original model if marked. (0.0.1.2)

- Updated
  [`eq_df_models()`](https://sfcheung.github.io/semeqmodels/reference/eq_df_models.md)
  and
  [`add_k()`](https://sfcheung.github.io/semeqmodels/reference/modified_models.md)
  to handle errors from
  [`modelbpp::gen_models()`](https://sfcheung.github.io/modelbpp/reference/model_set.html).
  (0.0.1.3)

- Made the progress bars of
  [`eq_df_models()`](https://sfcheung.github.io/semeqmodels/reference/eq_df_models.md)
  more informative. (0.0.1.4, 0.1.0)
